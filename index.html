The process

From a bare Windows machine to this page

01

Set up the baseline

One command inside WSL2 Ubuntu installs the pinned toolchain: Git, Python, Node, Bun, Godot 4.7.2, and OpenCode. Every download is checksum-verified.

02

Open the starter project

The script creates a minimal Godot project and leaves you in front of OpenCode. No agents, no commands, no extra setup.

03

Type one sentence

OpenCode planned the game, wrote the scenes and scripts, drew the art in code, synthesized the sound effects, and tested the result with headless Godot.
